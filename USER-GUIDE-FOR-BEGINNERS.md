# CloudCLI — гайд по интерфейсу для новичка

Этот документ — для человека, который раньше не пользовался Claude Code и
вообще не программист. Объясняю каждый экран простыми словами.

---

## 1. Первый вход

Открой ссылку сервера в браузере. Первый, кто заходит — сам придумывает логин
и пароль. Это единственный вход на сервер (регистрация после этого
закрывается) — сохрани пароль в надёжном месте, восстановить его самому
через интерфейс нельзя.

## 2. Подключение своего аккаунта Claude

Прежде чем писать агенту задачи, нужно подключить подписку:

**Settings (шестерёнка) → Агенты → Claude → «Войти снова»** — откроется
ссылка входа в Anthropic (владельца Claude). Логинишься там своим аккаунтом
— тем, на котором оформлена подписка Claude Code. После этого возвращаешься
в CloudCLI, всё готово к работе.

## 3. Главный экран — три колонки

- **Слева** — список проектов и сеансов (историй переписки).
- **По центру** — сам чат: сюда пишешь задачи, здесь агент отвечает.
- **Наверху по центру** — вкладки текущего проекта: **Chat** (чат),
  **Files** (файлы проекта), **Tasks** (список текущих/прошлых задач),
  иногда **Shell** (терминал, если не отключён администратором) и
  **Browser** (встроенный браузер для агента).

## 4. Проекты и сеансы (левая панель)

- **Проект** — это папка с кодом/документами, с которой работает агент
  (обычно — ваш git-репозиторий).
- **Новый проект** — кнопка сверху списка, указываешь путь к папке.
- **Сеанс** (Sessions) — отдельный диалог внутри проекта. Можно вести
  параллельно несколько сеансов по разным задачам в одном проекте.
- **Вкладка «Недавние»** — быстрый доступ к последним сеансам, не нужно
  каждый раз искать их по проектам.
- **Избранное** (Starred) — закрепить важные проекты наверху списка.

## 5. Как поставить задачу агенту

Внизу чата — обычное текстовое поле, пиши своими словами, что нужно сделать
(«собери отчёт по продажам за июнь из файла X», «напиши функцию, которая…»,
«разбери, почему падает скрипт Y»). Агент читает и меняет файлы проекта сам,
объясняет, что делает, по ходу задаёт уточняющие вопросы, если что-то неясно.

### Выбор модели

Рядом с полем ввода — кнопка **«Выбрать модель»**. Модели различаются по
скорости/цене и «сообразительности» — для простой рутины подойдёт модель
попроще и быстрее, для сложной задачи — самая мощная. Меняется прямо в
процессе диалога, без перезапуска.

### Уровень размышления (effort)

Рядом же — переключатель, насколько глубоко модель «думает» перед ответом.
Быстрее и дешевле — для рутинных задач. Медленнее, но основательнее — для
задач, где ошибка дорого стоит. Тоже переключается на лету.

## 6. Пока агент работает

- Можно свернуть браузер или заблокировать телефон — задача продолжает
  выполняться на сервере, не обрывается.
- Если стоит мобильное приложение (см. ниже) — придёт push-уведомление,
  когда задача готова, не нужно держать вкладку открытой и ждать.
- Кнопка «Стоп» останавливает текущий запуск, не теряя историю диалога — можно
  продолжить позже с того же места.

## 7. Счётчик токенов

Расход токенов (единиц, по которым тарифицируется подписка) виден по каждой
сессии — не нужно гадать, во что обошлась конкретная задача.

## 8. Файлы, задачи, терминал

- **Files** — можно посмотреть файлы проекта прямо в браузере, без скачивания.
- **Tasks** — список задач, которые ставились агенту, с их статусом.
- **Shell** (если доступен) — обычный терминал сервера. На части инстансов
  отключён специально — чтобы не нужно было разбираться в командной строке.

## 9. Настройки (шестерёнка вверху)

- **Внешний вид (Appearance)** — 12 визуальных тем, светлая/тёмная/др.
- **Агенты** — подключение/переподключение аккаунта Claude (см. пункт 2).
- **Уведомления** — push-уведомления о готовых задачах.
- **Голос** — голосовой ввод сообщений вместо печати.
- **API, Git, Browser-use, Tasks** — более технические разделы, обычному
  пользователю трогать не нужно, настроены при установке.

## 10. Мобильное приложение (телефон)

Открой сайт в браузере телефона → меню браузера → «Добавить на главный
экран». Иконка появится как обычное приложение, будут приходить
push-уведомления о готовых задачах — не нужно держать телефон с открытым
браузером.

## 11. Если что-то не работает

- Чат «завис» — можно смело закрыть вкладку и открыть заново, прогресс не
  теряется.
- Агент не отвечает совсем — проверь, что аккаунт Claude всё ещё подключён
  (Settings → Агенты — не истекла ли подписка/сессия входа).
- Любые другие сбои — пиши тому, кто настраивал сервер.
