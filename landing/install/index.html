Установка

Разверни на своём сервере сам

Пошаговый рунбук для тех, кто хочет поставить систему самостоятельно. Всё честно и по порядку: свой сервер, свой домен, свой аккаунт Claude — без VPN, примерно за час. Не хочешь возиться — разверну под ключ.

Что понадобится 1. Сервер 2. Настройка 3. Сборка 4. Установка 5. .env 6. Рабочая папка 7. Автозапуск 8. Домен и HTTPS 9. Вход + Claude 10. Телефон 11. Проверка

•Что понадобится

  • VPS (арендованный сервер) в России. Российский провайдер — значит без VPN и оплата обычной картой РФ. Хватает Ubuntu 22.04/24.04, 2 ядра, 2–4 ГБ памяти, 40 ГБ диска: сама модель считает на стороне Anthropic, сервер — лёгкий посредник.
  • Домен (или поддомен), который направите на этот сервер.
  • Аккаунт Claude с подпиской (Claude Max) — его подключите в конце, данные останутся только на вашем сервере.
  • Базовые навыки терминала — copy-paste команд по SSH. Если это не про вас — честнее взять «под ключ».

Про сборку: код Neo3 Agent System — проверенная приватная сборка (полгода боевых фиксов). Доступ к ней вы получаете при подключении (архивом или приглашением в репозиторий) — так вы гарантированно ставите рабочую версию, а не случайную копию. Все остальные шаги делаете сами.

1Арендуйте VPS

Возьмите у российского провайдера сервер на Ubuntu 22.04 или 24.04 LTS, 2 vCPU / 2–4 ГБ RAM / 40 ГБ диска. Получите root-доступ по SSH и добавьте свой ключ. Российский дата-центр = вход без VPN и оплата картой РФ.

2Базовая настройка сервера

Зайдите по SSH под root и поставьте зависимости и Node 22, затем заведите отдельного пользователя под сервис:

# зависимости apt update && apt install -y build-essential python3 git jq ripgrep sqlite3 curl # Node 22 curl -fsSL https://deb.nodesource.com/setup_22.x | bash - apt install -y nodejs # отдельный пользователь под сервис (не root) adduser --disabled-password --gecos "" neo3

3Получите сборку

Скачайте проверенную сборку Neo3 Agent System (доступ к репозиторию или архив вы получаете при подключении) и разместите её в домашней папке пользователя neo3:

su - neo3 # вариант с git-доступом, который вам выдали: git clone <ваш-доступ-к-сборке> ~/neo3 # или просто распакуйте присланный архив в ~/neo3 cd ~/neo3

4Установка и сборка

Ставим зависимости и собираем интерфейс:

npm install npm run build

Если npm install спотыкается на скачивании поискового движка ripgrep (бывает из-за фильтрации DNS у некоторых провайдеров) — обойдите так:

npm install --ignore-scripts npm rebuild better-sqlite3 cp "$(which rg)" node_modules/@vscode/ripgrep/bin/rg npm run build

5Настройте .env

В корне проекта создайте файл .env:

SERVER_PORT=3001 VITE_PORT=5173 HOST=127.0.0.1 # наружу отдаёт только Caddy (шаг 8) WORKSPACES_ROOT=/home/neo3/workspace DISABLE_TERMINAL=1 # без «сырого» терминала — безопаснее для команды

Не задавайте переменную VITE_IS_PLATFORM — оставьте её пустой. Она нужна для другого режима и в обычной установке всё ломает.

6Рабочая папка — «мозг бизнеса»

Рабочая папка агента — это обычная папка с файлами (ваш git-репозиторий), никакой отдельной «базы знаний» настраивать не нужно. Агент читает и меняет её как любой проект:

mkdir -p /home/neo3/workspace && cd /home/neo3/workspace git clone <репозиторий-вашего-проекта> project # или git init, если репо ещё нет

7Автозапуск (systemd)

Чтобы сервис сам поднимался после перезагрузки и сбоя, создайте /etc/systemd/system/neo3.service:

[Unit] Description=Neo3 Agent System After=network.target [Service] Type=simple User=neo3 WorkingDirectory=/home/neo3/neo3 EnvironmentFile=/home/neo3/neo3/.env ExecStart=/usr/bin/node dist-server/server/index.js Restart=always RestartSec=3 [Install] WantedBy=multi-user.target
systemctl daemon-reload systemctl enable --now neo3 systemctl status neo3 # убедитесь, что «active (running)»

8Домен и HTTPS (Caddy)

Самый простой путь к HTTPS — веб-сервер Caddy: он сам получает и продлевает сертификат. В стандартных репозиториях Ubuntu его нет, поэтому сначала добавьте официальный:

apt install -y debian-keyring debian-archive-keyring apt-transport-https curl curl -1sLf 'https://dl.cloudsmith.io/public/caddy/stable/gpg.key' \ | gpg --dearmor -o /usr/share/keyrings/caddy-stable-archive-keyring.gpg curl -1sLf 'https://dl.cloudsmith.io/public/caddy/stable/debian.deb.txt' \ | tee /etc/apt/sources.list.d/caddy-stable.list apt update && apt install -y caddy

В /etc/caddy/Caddyfile пропишите свой домен:

ваш-домен.ru { reverse_proxy 127.0.0.1:3001 }

Заведите у своего DNS-провайдера запись A: ваш-домен.ru → IP этого VPS, затем перезапустите Caddy. Как только домен зарезолвится — сертификат Let's Encrypt выпустится автоматически.

systemctl reload caddy

9Первый вход и подключение вашего Claude

  • Откройте https://ваш-домен.ru. Первый, кто зашёл, задаёт логин и пароль — после этого регистрация закрывается (весь ваш вход — один, команда работает под ним).
  • Дальше: Settings (шестерёнка) → Агенты → Claude → «Войти снова» — залогиньтесь в Anthropic своим аккаунтом, тем, на котором оформлена подписка.
  • Данные входа сохраняются только на вашем сервере — ни с чьей чужой подпиской не пересекаются.

Оплата подписки из РФ: прямой аккаунт Anthropic требует нероссийскую карту. Проще — через реселлера / OpenRouter обычной картой РФ (небольшая наценка за удобство оплаты). Оба пути рабочие.

10Приложение на телефонеНовое

Откройте сайт в браузере телефона → меню браузера → «Добавить на главный экран». Появится иконка как у обычного приложения, будут приходить push-уведомления о готовых задачах. Магазин приложений не нужен, установка ничего не весит.

11Проверка перед стартом

Прогоните короткий чек-лист — чтобы не ловить сюрпризы в рабочий момент:

  • Поставьте агенту реальную задачу — получите реальный ответ.
  • Посреди работы сверните вкладку / заблокируйте телефон на минуту и вернитесь — чат не должен «зависнуть» на «Running».
  • systemctl restart neo3 — сервис должен подняться сам, а вы — продолжить без потери прогресса.

Честно про движки: по-настоящему обкатан в бою пока Claude. Codex, Cursor, Kimi видны в переключателе как выбор — но самый предсказуемый результат сегодня на Claude.
