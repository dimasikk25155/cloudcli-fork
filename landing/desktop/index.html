Приложение для компьютера

Neo3 на вашем компьютере

То же самое, что в браузере, но отдельным окном: своя иконка в доке, вход не слетает, вкладки ничего не перекрывают. Скачайте файл для своей системы и запустите — установка занимает минуту.

Скачать для Mac файл .dmg · версия уточняется · размер уточняется Скачать для Windows файл .exe · версия уточняется · размер уточняется

Кнопка «для Mac» — для всех маков, выпущенных с конца 2020 года. У меня Mac постарше, на Intel Не уверены? Меню 🍎 → «Об этом Mac»: строка «Чип: Apple M…» — обычная кнопка, строка «Процессор: Intel» — ссылка рядом.

•Система ругнётся — это нормально

При первом запуске macOS скажет, что не может проверить разработчика, а Windows покажет синий экран SmartScreen. Пугаться нечего: так обе системы встречают любую программу без цифровой подписи — платного сертификата, который выдают Apple и Microsoft. Подпись — это про бумажку и ежегодный платёж, а не про то, что внутри файла.

Мы пока приложение не подписываем, поэтому предупреждение будет. Пройти его нужно один раз — при следующих запусках система больше не спросит. Файл вы качаете с нашего сайта, а не «откуда-то»: ссылки на этой странице ведут прямо на нашу сборку.

Если сомневаетесь — не ставьте молча, а напишите нам в Telegram: подскажем, что именно должно быть на экране, и пройдём установку вместе.

MacУстановка на macOS

Шаги ниже расписаны по macOS Sequoia (15). На других версиях названия кнопок в окне-предупреждении могут отличаться, но путь тот же: запустить → «Системные настройки» → «Конфиденциальность и безопасность» → разрешить запуск. Свою версию видно в меню 🍎 → «Об этом Mac».

  1. Нажмите «Скачать для Mac» и откройте скачанный файл Neo3-mac-arm64.dmg — двойным щелчком в папке «Загрузки» или в углу браузера.
  2. Откроется окно с иконкой Neo3 и папкой «Программы». Перетащите иконку Neo3 в «Программы» — это и есть установка.
  3. Откройте «Программы» (в Finder слева) и запустите Neo3 двойным щелчком.
  4. Появится окно о том, что система не может проверить разработчика. Закройте его кнопкой «Готово». Рядом может стоять «Переместить в Корзину» — вот её не нажимайте. Так и должно быть, дальше это чинится за два клика.
  5. Откройте «Системные настройки» → «Конфиденциальность и безопасность». Прокрутите вниз до раздела «Безопасность»: там будет строка про Neo3 и кнопка «Всё равно открыть» — нажмите её.
  6. Система переспросит — подтвердите «Открыть» и, если попросит, введите пароль от Mac. Neo3 запустится.

Дальше этого шага не будет. Разрешение выдаётся один раз для этой программы: со второго запуска Neo3 открывается как любое другое приложение — из дока или из «Программ».

WinУстановка на Windows

  1. Нажмите «Скачать для Windows» и запустите скачанный файл Neo3-win-x64.exe. Браузер может спросить, сохранять ли файл — сохраните.
  2. Появится синее окно «Система Windows защитила ваш компьютер». Кнопки «Выполнить» в нём сразу нет — сначала нажмите неприметную ссылку «Подробнее» в тексте.
  3. Под текстом появится кнопка «Выполнить в любом случае» — нажмите её.
  4. Начнётся установка, окно закроется само. Neo3 появится в меню «Пуск» и ярлыком на рабочем столе.

И здесь только один раз. SmartScreen предупреждает про сам файл установщика. Установленное приложение запускается обычным щелчком, никаких синих экранов больше не будет.

•Первый запуск

  • Приложение спросит адрес вашей системы — тот же адрес, по которому вы заходите в Neo3 из браузера (например, https://claude.neo3.ru). Вставьте его и нажмите «Продолжить».
  • Дальше — привычный вход логином и паролем. Вход сохраняется: закрыли приложение, открыли завтра — вы всё ещё внутри.
  • Адрес можно поменять потом: в меню приложения есть пункт «Сменить адрес сервера».
  • Обновления приложение проверяет само и предлагает полосой сверху. Согласились — оно скачает и поставит новую версию, вручную ничего искать не нужно. Проверить самому — пункт меню «Проверить обновления».

Сервера ещё нет? Приложение — это окно к вашей системе Neo3, а не отдельный продукт: сначала нужен адрес, куда подключаться. Как поднять систему самому — инструкция по установке, либо развернём под ключ.

Что-то пошло не так

Не открывается, не качается, система показывает не то, что написано выше — напишите и покажите скриншот. Разберёмся.
