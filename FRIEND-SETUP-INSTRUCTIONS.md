# Как поставить CloudCLI на свой сервер (для друга)

CloudCLI — веб-версия Claude Code (агент-кодер) с логином через браузер и
телефон. Ставится на твой собственный VPS-сервер, ты подключаешь свою личную
подписку Claude Code — никак не пересекается с моей.

Займёт минут 15-20, из них большую часть времени сервер сам себе ставит пакеты
и собирает код — тебе нужно будет ввести всего пару команд, без пересылки
ключей туда-сюда.

---

## Шаг 0. Что нужно перед началом

1. **Свой VPS** — чистый **Ubuntu 22.04 или 24.04**, root-доступ по SSH.
   Хватит самого дешёвого тарифа: 2 vCPU, 2–4 ГБ RAM, 40 ГБ диска (модель
   считает не на этом сервере, а на стороне Anthropic — сервер просто
   пробрасывает запросы).
2. IP-адрес этого сервера (понадобится мне для DNS).
3. Файл `install.sh` — пришлю тебе отдельно (просто текстовый скрипт, ничего
   секретного в нём нет, кроме одного служебного пароля для скачивания кода
   с моего сервера — он уже вписан внутрь).

---

## Шаг 1. Зайти на сервер по SSH

Из терминала на своём компьютере:

```bash
ssh root@<IP-твоего-сервера>
```

(Если пароль root не задавался при заказе VPS — обычно провайдер присылает
его в письме или в панели управления.)

## Шаг 2. Загрузить `install.sh` на сервер

Проще всего — открыть на сервере текстовый редактор и вставить содержимое
файла, который я тебе прислал:

```bash
nano install.sh
```

Вставь туда весь текст скрипта (правый клик → вставить, или Cmd/Ctrl+V),
затем сохрани: `Ctrl+O`, `Enter`, `Ctrl+X`.

(Если удобнее — можно закинуть файл через SFTP/SCP из любого клиента типа
FileZilla, WinSCP, или `scp install.sh root@<IP>:~/`, если умеешь.)

Сделай скрипт исполняемым:

```bash
chmod +x install.sh
```

## Шаг 3. Запустить установку — и всё, дальше сама

```bash
./install.sh <твой-поддомен>.neo3.ru --download
```

Вместо `<твой-поддомен>` — подставь любое короткое слово на латинице (я его
привяжу к DNS). Например: `./install.sh vasya.neo3.ru --download`.

Скрипт сам скачает код с моего сервера, поставит зависимости (`npm install`),
соберёт приложение, настроит автозапуск (сервис systemd) и веб-сервер (Caddy)
для HTTPS. Никого ждать не нужно — не закрывай терминал, займёт несколько
минут.

В конце появится сообщение вида:

```
Done. Server is up locally, waiting on DNS for public HTTPS.

Next steps:
  1. Point DNS A record: <домен> -> <IP-сервера>
  2. Once DNS resolves, visit https://<домен> — first visitor sets the admin password.
  3. Settings -> Агенты -> Claude -> "Войти снова" -> log in with your own
     Anthropic account (credentials stay on this VPS only).
```

Пришли мне это сообщение (или просто финальный IP) — дальше моя часть.

## Шаг 4. Я привязываю домен (моя часть)

Добавлю DNS-запись `<твой-поддомен>.neo3.ru → IP твоего сервера`. Обычно
применяется за пару минут, иногда до получаса.

## Шаг 5. Первый вход — делаешь сам

1. Открой в браузере `https://<твой-поддомен>.neo3.ru`.
2. **Первый, кто зайдёт — сам придумывает логин и пароль** — так и должно
   быть, регистрация после этого закрывается (это единственный аккаунт на
   сервере, специально для тебя).
3. Зайди в **Settings → Агенты → Claude → «Войти снова»** — откроется
   ссылка входа в Anthropic. Логинишься СВОИМ аккаунтом (той самой личной
   подпиской Claude Code). Данные входа хранятся только на твоём сервере —
   я их не вижу и доступа к ним не имею.
4. Напиши агенту любую тестовую задачу — должен прийти нормальный ответ.

Готово — дальше пользуешься как обычным Claude Code, только через браузер
(и с телефона тоже, добавь страницу на домашний экран — заработают пуш-
уведомления о готовых задачах).

---

## Если что-то пошло не так

- Скачивание кода упало с ошибкой доступа → напиши мне, возможно пароль на
  моей стороне сменился — пришлю обновлённый `install.sh`.
- Сайт не открывается по HTTPS → проверь, что DNS уже применился:
  `dig <домен>` (или https://dnschecker.org) — если IP ещё не тот, подожди.
  Caddy (веб-сервер) сам зациклится и повторит попытку получить сертификат.
- Приложение не отвечает → на сервере: `systemctl status cloudcli` — должно
  быть `active (running)`. Логи: `journalctl -u cloudcli -f`.
- Что-то совсем не так → пиши мне, разберёмся вместе.
