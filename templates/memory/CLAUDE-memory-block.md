## Память проекта (папка `memory/`)

В каждом проекте есть папка `memory/` — обычные `.md`-файлы, без базы данных.
Это долгая память: узнанное один раз не выясняется заново в следующей сессии.

**Читать.** Оглавление `memory/INDEX.md` подгружается автоматически в начале сессии.
Перед нетривиальной работой открой заметки, относящиеся к задаче.

**Писать** — по ходу работы и в конце, не дожидаясь конца диалога:
- установил/настроил → путь, версия, как запускать, где логи;
- долго искал баг → симптом + причина + фикс;
- принял решение → что выбрали, почему, что отвергли;
- сделал сервис/скрипт → runbook: запуск, проверка, логи.

**Как писать:**
- одна заметка = один факт, имя файла `kebab-case.md`;
- только факты, списками; без воды и пересказа диалога;
- новую заметку добавь строкой в `memory/INDEX.md`;
- перед созданием проверь, нет ли уже заметки по теме — обновляй, не плоди дубли;
- секреты (пароли, токены, ключи) в заметки не писать — только ссылка на `.env`.

Тривиальная правка (опечатка, отступ, косметика) — записывать не нужно.
