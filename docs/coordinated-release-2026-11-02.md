# Один общий выпуск после соседних сессий

Пользователь 02.11.2026 согласовал применение аудита Codex с условием: дождаться
завершения соседних работ и сделать один общий рестарт. Отдельного повторного
подтверждения на этот выпуск не требуется.

Сторож — детерминированная программа `scripts/coordinated-local-release.mjs`,
запускаемая отдельным Mac LaunchAgent `com.dimasik.neo3-coordinated-release`.
Она не вызывает модель, не устанавливает зависимости, не делает Git commit/push,
не меняет исходники соседних задач и не отправляет сообщения в Telegram.
Исполняемая копия закреплена вне рабочего дерева, чтобы текущие правки не меняли
самого сторожа в процессе наблюдения.

## Условия

- Сохранён исходный PID Neo3 и отпечатки обеих работающих сборок. Чужой рестарт
  или замена артефактов отменяют этот выпуск, чтобы не было второго рестарта.
- Нет работающих сессий и неизвестных дочерних процессов сервера. Исключается
  только постоянный plugin host; собственная сессия наблюдателя не исключается.
- Отслеживаемые сессии этого проекта дошли до `done`. `waiting`/`failed` сами по
  себе не считаются завершённой работой.
- Задачи и проверка текущего автопилота закончены. Согласие пользователя на общий
  выпуск покрывает финальный этап применения после `review:done`; отдельные
  вопросы (`waiting.kind=question`) и незаконченные задачи по-прежнему блокируют
  выпуск. Для точечного согласования поддерживается отпечаток известной записи.
- Две минуты одновременно нет активности и изменений исходников.
- Полные тесты, типы и изолированные сборки проходят. После них ещё раз сверяются
  исходники и активность. Если работа возобновилась после замены папок, старые
  сборки возвращаются до рестарта; наблюдение продолжается с новым интервалом тишины.
- Перед заменой сборок создаётся SQLite-backup базы с учётом WAL и проверкой
  целостности. Доступ только владельцу; содержимое в журналы не выводится.
- Одна попытка рестарта записывается на диск ДО команды launchctl. Автоматического
  повторного рестарта, в том числе после сбоя проверки, нет.
- После рестарта проверяются новый PID, HTTP 200 локального и публичного адресов,
  имя и SHA-256 фактически отданного клиентского пакета. Это smoke-проверка,
  не замена полного браузерного E2E.

Наблюдение ограничено 24 часами; истечение срока не разрешает принудительный рестарт.
Ошибка проверки останавливает выпуск с сохранённой причиной. Во время сна Mac
проверки не выполняются; после пробуждения процесс продолжает работу.

## Состояние и остановка

Рабочая папка: `~/.cloudcli/maintenance/coordinated-release-20261102/`.

- `status.json` — этап, причины ожидания, время последнего наблюдения и итог.
- `checks.log` — проверки и сборка; `watcher.log` / `watcher.error.log` — процесс.
- `manifest.json` — согласованная цель, исходный PID и отпечатки, срок наблюдения.
- `dist.before` / `dist-server.before` — откат после применения; не удалять до проверки.
- `auth.before.db` — резервная копия базы до новых миграций; автоматический откат
  базы не выполняется, чтобы не потерять более поздние пользовательские записи.

```sh
launchctl print "gui/$(id -u)/com.dimasik.neo3-coordinated-release"
cat ~/.cloudcli/maintenance/coordinated-release-20261102/status.json
```

Отмена до применения:

```sh
launchctl bootout "gui/$(id -u)/com.dimasik.neo3-coordinated-release"
```

Не запускать параллельно другой деплой/рестарт. Если он всё же произошёл, этот
сторож завершится с причиной; это не подтверждает применение всех исправлений.

Проверка защитных условий: `node --test scripts/coordinated-local-release.test.mjs`.
