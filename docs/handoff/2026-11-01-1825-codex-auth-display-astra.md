## Разведка кода и план диагностики для Astra

1. **Сначала установить, что реально запущено.** Сравнить исполняемый dist с
   исходниками, CLI внутри SDK и `/usr/local/bin/codex`, версии/пути/обёртки;
   HOME/CODEX_HOME и пользователя агента на VPS. Не печатать env целиком или auth.json.
   Зафиксировать актуальный статус до любой новой попытки.
2. **Разобрать смену auth-состояния.** Проверить по установленному CLI/его исходникам,
   что делает `codex login --device-auth` с существующей авторизацией при старте,
   отказе и тайм-ауте. Предположение: новая попытка могла сбросить прежний вход —
   пока НЕ доказано. Уточнить, чей и какой auth store проверяет каждая команда;
   старая сохранённая сессия не доказывает принятие кода из текущей попытки.
3. **Сопоставить одну попытку от начала до конца.** Если новая попытка действительно
   необходима и Дима готов её подтвердить: только один живой процесс, уникальный
   request/run id, фактическое время выдачи/TTL, свежий вывод из нужной Herdr-панели,
   одноразовый код в ответ пользователю. Не переиспользовать терминальный хвост с
   прежним кодом. Не запускать другие auth-процессы и не делать logout вслепую.
4. **Проверить Neo3 ↔ Codex ↔ отображение.** Это явная просьба Димы для следующей

   подмену текущего вывода историей, потерю вывода при reconnect/резюме. Это гипотезы:
   сначала воспроизвести с двумя разными безопасными маркерами, затем исправлять.

## Известные грабли, уже исправленные в исходниках

- Codex interactive с выключенным code_mode_host прекращает работу при shared
  background server. Добавлен `--no-daemon`; без него Herdr может сначала вернуть
  idle, а затем CLI завершится с ошибкой. Проверка запуска ≠ ответ модели.
- Непросмотренное завершение Herdr — `done`, не только idle. Нормализуется в idle,
  ожидание: `--until idle --until done`. Иначе реальный ответ есть, а wait даёт timeout.
- Herdr agent_not_found приходит JSON на stderr; helper читает stdout ИЛИ stderr.
- Историю Codex читать по текущему id/cwd, не брать последний чат всего пользователя.
- Одноразовый SSH-процесс ожидания входа может исчезнуть при смене хода/соединения.
  Постоянная Herdr-панель живёт независимо; последнюю панель этой задачи уже закрыли.

## Минимальные проверки при продолжении

Тесты запускаются только с временными HOME и DATABASE_PATH. Полный `npm test`
делает это сам; выборочные tsx — вручную так же. Серверный alias @/ указывает
на server/. `npm run typecheck` ничего не пишет; обычный npm run build трогает
живые dist и сейчас не подходит. Для серверной изолированной сборки нужны tsc
с отдельным outDir И затем tsc-alias с тем же outDir.

Критерий следующего этапа: воспроизведено/объяснено расхождение UI и auth;
свежая попытка (если нужна) однозначно связана с живым процессом; в Neo3 отображается
свежий ответ нужного прогона без дублей/подмены; актуальный серверный запрос работает;
остатки совместимости модов перечислены честно. Диме не приходится повторно
вводить уже выданные/истёкшие коды и доказывать скриншотами, что UI показывает ошибку.
