## 3. Исправить обработку — выполнено в исходниках

- PCM16 mono WAV делится на части до 60 секунд, с поиском тихой границы и перекрытием 0,6 секунды. Тест сверяет все исходные аудиосэмплы, включая последний.
- Обработка частей последовательная. Ошибка/неожиданно пустой результат одной части не превращается в успешную частичную диктовку. CLI повторяет пустую часть без подсказки словаря, затем возвращает ошибку с возможностью повтора.
- Метаданные тишины больше не удаляют настоящую речь. Широкие шаблоны с произвольным хвостом убраны. DimaTorzok удаляется точечно в начале предложения, без соседнего текста. Упоминание этой фразы внутри осмысленного предложения сохраняется.
- Повтор целого предложения больше не удаляется автоматически. Совпадения объединяются только на стыках аудиочастей.
- Корректор обязан сохранить все распознанные слова после нормализации по словарю, включая конец. При потере слов, пустом ответе, незавершённой генерации или сетевой ошибке остаётся полная исходная расшифровка. При включённой очистке допускается удаление только проверяемых междометий `э`, `эм`, `ну`; изменения по словарю учитываются отдельно.
- Канонический словарь CLI дополняется пользовательским, сохраняя правила сленга. Чтение пустых списков и комментариев исправлено. Весь словарь поступает корректору; подсказка Whisper по-прежнему ограничена и содержит только целые термины.
- Прямой браузерный backend использует те же правила очистки и защиты коррекции.
- CLI сохраняет оригинал на устройстве через IndexedDB: промежуточные порции во время записи и полную запись до сетевого запроса. Восстановление привязано к пользователю, проекту и чату. После перезагрузки в том же браузере и на том же адресе можно повторить распознавание или скачать оригинал. Восстановленная запись не отправляется автоматически в чат.
- Успешная расшифровка также сохраняется перед вставкой: если вставка не состоялась, её можно восстановить без сети. После подтверждённого вызова вставки удаляется только собственная запись; другие записи не затрагиваются.
- Если хранилище заблокировано или закончилось место, показывается явное предупреждение, оригинал остаётся в памяти доступным для скачивания. Очистка данных сайта/приватного окна, сбой диска и ещё не записанная последняя порция при аварийном закрытии не покрываются гарантией восстановления. Прерванная запись отмечается отдельно. Удаление данных браузером возможно — для особо важной диктовки остаётся скачивание оригинала.
- Запрос ограничен 90 секундами, повторы конечны. Ошибка сети не превращается в пустой успех и не удаляет резервную запись.
- CLI сравнивает длительность декодированного аудио со временем записи; явный обрыв не отправляется как полноценная диктовка. При невозможности декодировать оригинал остаётся доступным для скачивания.
- Mac/Windows сохраняют тихую речь и последний буфер. `audioop`, отсутствующий в новых Python, заменён. До сетевого запроса полная запись копируется в `failed/` через временный файл, fsync и атомарное переименование. Ошибка распознавания или резервного копирования никогда не удаляет оригинал. В меню добавлен «Повторить сохранённую запись», доступный и после перезапуска приложения. Долгая обработка не сбрасывает состояние до завершения worker.
- Python перечитывает словарь перед следующей диктовкой. Длительность истории берётся из WAV-заголовка.
