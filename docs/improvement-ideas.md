# Идеи улучшений в Neo3

Мод `modImprovementIdeas` включён по умолчанию и доступен администратору. После успешного завершения прогона сервер извлекает явные блоки «💡 Что можно улучшить дальше:» из ответов Claude/Codex/Grok. Вкладка может быть закрыта. Никакая идея не запускается автоматически.

В чате над полем ввода показаны идеи текущего проекта. «Реализовать» запускает один ход в исходном чате с одобренным текстом; «Позже» оставляет идею в раскрываемом списке. Повторное нажатие не запускает второй ход. Занятый чат отклоняет запуск с возможностью повторить. Режим только чтения не повышается автоматически. Модель, effort и права берутся из последнего запуска; после рестарта — сохранённые модель/effort и обычные права. Состояние «Запущено» означает только успешный старт: результат проверяется в исходном чате.

## Память и поиск

SQLite: таблица `improvement_ideas`, одна идея по user/project/нормализованному тексту. В Obsidian — `wiki/ideas/neo3-<hash>.md`, один реестр проекта и владельца. Путь берётся из `NEO3_VAULT_DIR` либо существующего стандартного вольта. В файле есть проект, точный текст предложения, дата, исходный чат и статус. Предложения явно отделены от фактов о завершённой работе.

При вопросе пользователя «что можно улучшить / что предлагали» будущий агент ищет:

```sh
rg -li 'название проекта|слова идеи' '<vault>/wiki/ideas'
```

Затем читает найденный реестр и учитывает статус. Управляемый блок `neo3-ideas:start/end` обновляется атомарно; человеческий текст снаружи сохраняется. Чужие файлы и симлинки не перезаписываются. Секретоподобные предложения не сохраняются. Ошибка записи в Obsidian оставляет идею в Neo3 и кнопку «Повторить запись». После прерванного запуска статус `starting` не ретраится автоматически: нужно проверить исходный чат.

Сбор начинается с момента применения мода; массового импорта прошлых чатов нет. Выключатель прекращает захват, скрывает карточки и блокирует действия. Отложенные идеи остаются в базе.

## API

Authenticated admin:
- `GET /api/improvement-ideas?sessionId=...` — идеи проекта этой сессии.
- `POST /api/improvement-ideas/:id/decision {action:"implement"|"later"}`.
- `POST /api/improvement-ideas/:id/sync` — повторить запись в Obsidian.

Реальный запуск идеи моделью и браузерная проверка не заявляются: общий Edge по разрешённому пути отсутствует (ENOENT), другие браузеры не запускались.
