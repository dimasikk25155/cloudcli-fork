Почему имена отличаются от ролика: в Claude Code уже есть встроенные `/doctor`, `/skill-doctor` и
`/advisor`, поэтому навыки названы `setup-doctor`, `skill-audit`, `second-opinion`. В Neo3 команды
`/doctor`, `/skill-doctor`, `/advisor` — собственные команды Neo3: сервер перехватывает их до движка,
конфликта нет.

Ничего в `~/.claude`, `~/.codex`, `~/.grok` не удалялось и не переносилось.

### Как подключить строку состояния (по согласию Димы)
1. `cp ~/.claude/settings.json ~/.claude/settings.json.bak-20261104`
2. заменить только ключ `statusLine` на
   `{"type":"command","command":"node ~/.claude/statusline/neo3-statusline.mjs","padding":0}`
3. проверить, что файл читается: `node -e 'JSON.parse(require("fs").readFileSync(process.env.HOME+"/.claude/settings.json","utf8"))'`

Откат — вернуть копию или прежнюю команду `npx -y ccusage statusline`.
Источники лимитов в строке: `rate_limits` из stdin Claude Code → кэш `~/.cloudcli/statusline-cache.json`
(до 60 с) → тот же endpoint, что у Neo3, не чаще раза в минуту. Нет данных — `лимиты: ?`, не ноль.

## 1. Среда (сделано при установке пакета)

- Терминальный Claude Code 2.1.x установлен; графическое приложение с вкладкой Code не используется —
  интерфейс ролика в терминале не обещаем.
- Версии, навыки, MCP сверены `/setup-doctor` и `/doctor` Neo3 без значений секретов.
- Протокол Димы, режимы, модель, effort, права и пользовательские настройки сохранены.
- Перед правкой настроек — адресная копия; ключевые папки не удаляются и не переносятся.

## 2. Рабочий профиль

- Русский интерфейс и простые ответы — уже в правилах Димы.
- Запреты на чтение секретов и разрушительные действия — уже действуют (страж секретов, страж
  удаления, `protect-core-dirs`). Чужой `settings.json` целиком не копируется.
- Уведомления о вопросе и завершении — один канал: «Ждут тебя» Neo3 (пуш, Telegram).
- Remote Control и «не засыпать» — отдельные переключатели. В Neo3 «не засыпать» сделан модом
  (`caffeinate` только пока идут прогоны). Remote Control Claude не включался — Neo3 и так веб-приложение.

## 3. Три мода автора — что в терминале

1. **Контекст и лимиты:** строка состояния (выше) — установлена, ждёт подключения. В Neo3 — карточка
   «Контекст и лимиты» на рабочем столе.
2. **Session Hub:** в терминале не воспроизводится; в Neo3 — полоса и панель диалогов.
3. **Handoff:** в терминале — навык `/handoff` (уже был); в Neo3 — «Эстафета» и «Перенести».
   Порог Neo3 50% / 400K / 12 ч не менялся под 60% ролика.

## 6. Диагностика и советник

- Наличие встроенных `/skill-doctor`, `/doctor`, `/advisor` в установленной версии проверено —
  поэтому свои навыки названы иначе (выше).
- Аудит навыков и окружения — только отчёт, без удаления и без значений ключей.
- Советник: одна модель на разовый вызов, явный лимит; основной движок не меняется.
- Autopilot 2.2.0 установлен; не переустанавливался ради ролика.
