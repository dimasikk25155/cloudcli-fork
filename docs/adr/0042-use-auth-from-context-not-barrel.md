# 0042. В коде, который грузят тесты, `useAuth` берётся из файла контекста, а не из бочки

**Статус:** принято

## Контекст

План исходил из того, что `useAuth` можно импортировать из общего входа модуля авторизации, как делает остальной код. Тесты под node при этом падали: бочка тянет терминал и стили `xterm.css`, которых в node нет (дефект D01).

## Решение

В модулях, которые загружаются тестами, `useAuth` импортируется напрямую из файла контекста авторизации. Бочка в таком коде не используется.

## Почему

Отвергнуто подставлять заглушку для `xterm.css` в тестовом запуске: она прячет настоящую связь и тихо тащит терминал в каждый тест темы. Отвергнуто разрезать бочку: она нужна остальному приложению, и правка задела бы чужой код. Прямой импорт точечный и ничего не меняет в работе приложения.

## Последствия

Отдельной защиты от ошибки в описании сборки нет: новый импорт через бочку в таком модуле снова сломает тесты, и выяснится это только при запуске. Два способа взять один хук остаются в кодовой базе. Любой модуль, у которого появится тест, придётся проверять на то же самое.
