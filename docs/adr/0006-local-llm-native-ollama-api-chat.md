# 0006. Локальная модель через нативный Ollama /api/chat (D01)

**Статус:** принято, 2026-10-12

## Контекст

Чипы-ответы (R24) и предложения заметок (R30) генерирует бесплатная локальная модель
на Ollama. Нужен короткий ответ строго в JSON, без рассуждений. На таске 05 выяснилось
(D01): OpenAI-совместимый путь Ollama `/v1/chat/completions` игнорирует `think:false` —
модель уходит в рассуждения и обрезается. Пробный вызов: 7,6 с без ответа. Нативный
`/api/chat` с `think:false` и `format:json`: 0,65 с и валидный JSON (проверено
2026-10-12).

## Решение

- Общий серверный хелпер `local-llm` для обоих модулей: нативный `/api/chat` Ollama,
  `think:false`, `format:json`, таймаут, разбор ответа и откат к «ничего».
- Адрес — `LOCAL_LLM_BASE_URL`; модели из env: для чипов по умолчанию `qwen3:8b`, для
  заметок `qwen3.5:9b`.
- Недоступная модель не показывает ошибок: чипов нет, заметка не предлагается.

## Рассмотренные варианты

- **OpenAI-совместимый `/v1/chat/completions`** — не выключает рассуждения (D01), ответ
  медленный и обрезанный.
- **Облачная модель** — платно и мимо смысла «бесплатно, локально».
- **Свой вызов в каждом модуле** — дублирование разбора JSON и ретраев.

## Последствия

- Код привязан к нативному протоколу Ollama; смена бэкенда (vLLM, облако) потребует
  второй реализации хелпера.
- Работа функций зависит от доступности Windows-сервера с Ollama; деградация молчаливая.
- Совместимость с будущими версиями Ollama проверяется на нативном пути, а не на
  OpenAI-совместимом.
