# 0025. Копия документа с мостом отдаётся через грант file-preview, а не через srcdoc

**Статус:** принято

## Контекст

Для режима «Правка» в iframe нужно показать копию HTML с вставленным мостом. Страница ссылается на картинки и CSS по относительным путям, а превью уже изолировано: `sandbox="allow-scripts"`, CSP с `connect-src 'none'`.

## Решение

В file-preview добавлен грант «копия документа»: сервер хранит присланный клиентом HTML (до 2 МБ) в памяти гранта и отдаёт его по адресу исходного файла внутри токена. Остальные пути гранта читаются с диска как раньше, CSP прежняя. Не больше 20 таких грантов на процесс, старые вытесняются.

## Почему

Отвергнуто: `srcdoc`. У него нет базового адреса, относительные картинки и CSS ломаются, а ослабить `base-uri 'none'` значило бы расширить поверхность атаки в песочнице. Отвергнуто: писать копию с мостом на диск рядом с файлом — загрязняет проект Димы и риск, что копия попадёт в коммит. Грант в памяти даёт правильный базовый адрес, не трогает диск и использует уже проверенные токен, TTL и запрет приватных сегментов.

## Последствия

Сервер теперь держит в памяти присланный клиентом HTML; лимит 2 МБ и 20 грантов защищают память, но вытесненный грант в открытой вкладке перестаёт отдавать копию, и превью придётся пересоздавать. Тело запроса до 3 МБ требует собственного лимита `express.json` на роуте. Мост работает в iframe без same-origin, поэтому обмен идёт через `postMessage` с проверкой `event.source` и одноразового ключа, а данные моста считаются недоверенными.
