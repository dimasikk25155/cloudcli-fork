# 0007. Ограничения фоновой проверки памяти

**Статус:** принято, 2026-10-12

## Контекст

Вместо Stop-хука Neo3 сам предлагает заметку для вольта, когда сессия закончилась
(R30–R32). Сессии в Neo3 явно не закрываются, поэтому «закончилась» нужно определить
(R38i). Разбор идёт через локальную модель на Windows, которая может быть недоступна, а
история сессий большая: первый запуск не должен прогнать через модель всё.

## Решение

- Фоновая проверка в процессе сервера раз в 10 минут, только для сессий админа.
- Сессия считается законченной: 30 минут без активности, не меньше двух сообщений
  пользователя и были правки файлов или команды (вызовы инструментов правки и
  выполнения у всех движков).
- Сессии, затихшие больше суток назад, не разбираются (уточнено на таске 07).
- Не больше 3 вызовов модели за один проход; при недоступности модели всего до 3
  попыток на сессию, затем отказ (уточнено на таске 07).
- Транскрипт обрезается до ~60K символов с конца, секреты вычищаются до отправки.
- Модель сама решает, стоит ли заметка; папка принимается только из списка правил
  вольта, иначе `wiki/synthesis`. Запись — только по кнопке, без перезаписи (занято —
  суффикс).

## Рассмотренные варианты

- **Явная кнопка «завершить сессию»** — Дима ей пользоваться не будет, сессии висят.
- **Разбирать всю историю** — первый запуск забил бы модель на часы.
- **Безлимитные повторы при ошибке** — бесконечная долбёжка недоступной Windows.
- **Записывать заметку автоматически** — мусор в вольте без контроля.

## Последствия

- Сессии старше суток на момент включения заметок не получат никогда.
- Сессия без правок и команд (чистое обсуждение) заметку не получит.
- Пропускная способность ограничена тремя сессиями за 10 минут; при всплеске очередь
  разбирается с задержкой.
- Отказ после трёх попыток окончателен: при долгом простое Windows часть сессий
  останется без заметки.
