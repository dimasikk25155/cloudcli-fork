# 0018. Агент диска мака — плагин Claude Code `mac-disk` плюс общий навык `/disk`

**Статус:** принято, 2026-10-14

## Контекст

Страж удаления, уборщик, сохранятель и ночная задача разбросаны по пяти местам (`task-killer/`,
`~/.claude/settings.json`, launchd); их надо собрать в одно, включаемое и выключаемое (R15).

## Решение

- Плагин Claude Code в `~/.claude/local-plugins/mac-disk` со своей локальной площадкой,
  включён на уровне пользователя. Внутри: хук стража через `${CLAUDE_PLUGIN_ROOT}`, команда
  `disk` («/disk», «убрать сейчас», «установить»), скрипты уборщика и сохранятеля.
- Ночная задача `com.dima.mac-cleanup` запускает скрипты из плагина; в `task-killer/` остаётся
  записка «переехало»; прежняя запись хука в настройках удаляется (бэкап `.bak-mac-disk-<дата>`).
- `/disk` дополнительно оформлен как общий навык `~/.claude/skills/disk`, вызывающий те же
  скрипты, — его видят Codex и Grok.
- Подушка 5 ГБ, сторож памяти, `disk-reserve` и `tyres-disk-audit` остаются вне плагина.

## Почему

- Отвергнуто: мод Neo3 — диск мака живёт вне Neo3 и нужен в обычном терминале.
- Отвергнуто: оставить хук в `settings.json` рядом с плагином — два одинаковых стража.
- Отвергнуто: только навык — страж удаления требует хука, навык его не даёт.
- Отвергнуто: только плагин — Codex и Grok плагины Claude не подхватывают и потеряли бы `/disk`.

## Последствия

- Ночная уборка зависит от пути плагина: переустановка или перенос папки без
  «/disk установить» тихо ломает расписание.
- Страж удаления работает только в Claude Code; в Codex и Grok его нет.
- Две точки входа (`disk` в плагине и в навыках) должны вызывать один скрипт, иначе разойдутся.
- Выключение плагина снимает и страж, и команду одновременно.
