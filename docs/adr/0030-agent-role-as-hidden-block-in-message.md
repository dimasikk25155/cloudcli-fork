# 0030. Роль агента — скрытый блок в первом сообщении, а не системный промпт

**Статус:** принято

## Контекст

Агент Neo3 — это именованная роль с правилами проверки, файлами-знаниями и версионной памятью. Работать он должен на Claude, Codex и Grok. Системный промпт у движков устроен по-разному: у Claude есть дополнение к пресету, у Grok и Codex свои отдельные пути для режима работы.

## Решение

Роль, правила самопроверки, пути файлов и текущая версия памяти собираются в блок `<agent_brief>` и кладутся перед текстом задачи в первом сообщении. Блок входит в список «только для агента» и срезается везде, где текст видит человек: в пузырях и заголовках сессий.

## Почему

Отвергнут системный промпт: это три разные реализации под три движка, и одна из них может расходиться с остальными. Пришлось бы менять запуск каждого CLI, а правка там ломается при обновлении движка. Отвергнута запись роли в `CLAUDE.md` или `.claude/agents` проекта: это работает только у Claude и подмешивает роль всем чатам папки, а не одному. Блок в сообщении уже применяется для `<screenshot_context>`, механизм срезания готов.

## Последствия

Роль есть только в первом сообщении. Движок может «забыть» её в очень длинном чате, и чат придётся переносить эстафетой. Правка роли или памяти не меняет уже начатые чаты, новую версию получает только новый. Роль весит как обычный текст и занимает контекст. Роль слабее системного промпта: прямая просьба пользователя в чате способна её перебить. Новый вид скрытого блока нужно помнить во всех местах, где показывается текст сессий.
