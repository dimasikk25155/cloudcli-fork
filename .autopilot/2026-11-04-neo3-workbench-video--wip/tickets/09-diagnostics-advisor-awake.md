## Что должно заработать

`/doctor` — отчёт: движки (установлены, версия, вход), MCP и регистрация neo3-threads, Ollama-туннель, место на диске, размер базы, служба Neo3; статусы ok/warn/fail/unknown; ключи не показываются; починка не автоматическая. `/skill-doctor` — отчёт по навыкам Claude и Codex: дубли имён, пустые описания, битые ссылки, конфликты; ничего не удаляется. Оба — админ. `/advisor <вопрос>` — вопрос сильной модели (Claude Opus, `runHeadlessPrompt({readOnly:true})`) с последними сообщениями чата; ответ во вкладке холста `advisor`; один вызов на команду; при лимите `checkUsageGuard` — отказ с причиной; модель текущей сессии не меняется. Работает из чатов всех трёх движков.

«Не засыпать»: пока есть работающие прогоны (`sessionAttention`, состояние working) — дочерний `caffeinate -i`; нет работающих 2 мин — процесс снимается; не дольше 3 ч без новой активности; не macOS — ничего. Мод `modKeepAwake`; `/doctor`, `/skill-doctor`, `/advisor` — `modDiagnostics`.

## Критерии приёмки

- [ ] `runDoctor` на фейковом `exec`/`fs` даёт отчёт со всеми проверками; в выводе нет значений из `.secrets*`/`.env` — тест
