## Что должно заработать

Над полем ввода — полоса диалогов: «работают N · ждут N · готово N» по всем доступным проектам. Клик открывает боковую панель: списки по состояниям, проект, движок, переход в сессию, «прочитано» (не останавливает и не завершает задачу). Данные — `useAttention()`.

В панели — «Мастер-сессия»: все ждущие вопросы по проектам пользователя (Диме — все его, через `projectAccessFor`). На каждый — выбор варианта или текст ответа. «Подготовить ответы» — черновики от модели (readOnly headless, как у Дуэта), которые можно править. Экран проверки: «чат → текст ответа», «Отправить всё» одним действием. Доставка: структурный вопрос — `pendingAnswers.answer()`, текстовый — обычное сообщение в чат через `beginChatSend`. Если состояние чата изменилось после подготовки — «вопрос изменился», не отправляется. Повторное нажатие не шлёт дважды (`batchId`). Мод `modSessionHub`.

## Критерии приёмки

- [ ] Полоса и панель показывают реальные состояния сессий Claude, Codex и Grok; «прочитано» меняет только отметку
- [ ] `GET /api/master-session/questions` возвращает только доступные пользователю ждущие вопросы — тест админ / не-админ
- [ ] `POST /drafts` при сбое модели отдаёт понятную ошибку, черновики можно не использовать
- [ ] `POST /send`: структурный и текстовый ответ доставляются; устаревший (`expectedUpdatedAt` не совпал) → `stale`; повтор того же `batchId` не доставляет второй раз — тесты на фейках
- [ ] Экран проверки показывает адресатов и тексты до отправки; мод выкл — полосы и панели нет, роуты `409 MOD_OFF`
