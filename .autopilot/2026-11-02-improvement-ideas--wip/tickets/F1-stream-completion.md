## Критерии приёмки
- [ ] Служебные события не завершают assistant block; snapshot заменяет соответствующие deltas независимо от случайного id; переполнение буфера не превращает обрезанный текст в самостоятельную идею. Проверить последовательностью реальных нормализованных кадров, включая snapshot с другим id.
- [ ] Воспроизведение: delta «💡 Что можно улучшить дальше: Использовать https://sample» -> background_tasks -> delta «:sample@example.invalid» -> stream_end -> full snapshot -> complete не сохраняет частичную идею. Проверка секретов применяется ко всему блоку.
- [ ] После временной ошибки GET успешный poll очищает ошибку загрузки, сохраняя независимую ошибку действия при необходимости.
- [ ] Завершение старого action после перехода в другой чат не меняет error/pending нового чата; race regression.

## Ограничения
Только указанная зона. Не переделывать сервис/DB/API, не менять production. Tests temporary HOME/DB; typecheck. До правки прочитать файлы, воспроизвести дефект. Тесты должны проверять поведение, не точный текст реализации. Не вводить новый слой без необходимости.
