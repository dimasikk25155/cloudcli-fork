# F1 — Запрет приватных файлов по настоящему пути артефакта

**Требования:** R12
**Зависит от:** —
**Зона:** `server/modules/artifacts/`
**Волна:** 5
**Ревью:** да — ремонт ветки
**Модель:** сильная

## Что должно заработать

Запрет на `.env`, `.secrets*`, `.git`, `.ssh` в артефактах проверяется не только по запрошенному пути, но и по настоящему (после разрешения симлинков, относительно настоящей папки проекта). Ссылка внутри проекта на приватный файл не публикуется и не копируется в снимки.

## Из брифа, дословно

> «всякие разные вкладочки делать полезные там инфографику и так далее для всего этого»

## Разделы спецификации

Истории 21, 24; правило `interfaces.md` «.env, .secrets* не читать в агентных инструментах».

- [ ] `server/modules/artifacts/artifacts.service.ts:169` (с `:189`): запрет `.env`, `.secrets*`, `.git`, `.ssh` проверяется по реальному пути относительно настоящей папки проекта; тест: `docs/a.md → ../.env` внутри проекта → `artifact.publish`/`publish` получает 400 `ARTIFACT_PATH_PRIVATE`, снимок не создаётся
- [ ] Тот же запрет при `refresh` (файл стал ссылкой на приватный после публикации) — отказ, новая версия не создаётся
