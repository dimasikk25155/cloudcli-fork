# Спецификация: Рабочий стол Neo3 по двум роликам, светлая тема Claude, паритет модов

## Задача
«Тупой чат-бот… слева чат и слева сессии» надоел. В ролике про Claude Code 2.0 Дима увидел светлый рабочий экран: чат слева, большой экран с полезными вкладками и инфографикой справа, панели диалогов и лимитов, побочные вопросы, вложенные сессии, мастер-сессию. Codex всё это выписал, но не построил; моды на Codex перенёс наполовину; ролик Jev превратил в CLI, который ни один движок не умеет запускать. Дима хочет одной сборкой получить это у себя — на Claude, Codex и Grok, с Claude как главным движком, — плюс видеть у каждого ответа, сколько агент думал.

## Решение
- Новая светлая тема «Светлая Claude» в духе приложения Claude; Диме включается сразу, старые темы остаются.
- Переключаемый «Рабочий стол»: чат слева, справа большой холст с вкладками — инспектор сессии, контекст и лимиты, артефакты, побочные чаты, второй чат. Обычный вид чата остаётся.
- Артефакты (документы, HTML-инфографика, слайды, отчёт Jev) открываются крупно, у них есть версии и комментарии к участку, которые уходят агенту на правку.
- Панель диалогов: полоса над полем ввода и боковая панель «работают / ждут / готово» по всем проектам; мастер-сессия собирает вопросы всех чатов и отправляет ответы пачкой после показа адресатов.
- Побочный чат /btw по цитате, дерево вложенных сессий, два чата рядом, группы и закрепы проектов и чатов, которыми агент тоже может управлять.
- /doctor, /skill-doctor, /advisor, профиль настроек с предпросмотром и снимком, «не засыпать, пока идут прогоны».
- У каждого ответа: «Думал N с · ответ за N с», сохраняется в истории.
- Паритет модов: «Фон: N» у Codex, «Стоп» фоновой задачи у Codex и Grok там, где движок даёт способ остановить, честные подписи «что работает в каком движке».
- Терминальный Claude Code получает строку состояния с контекстом и лимитами, навыки диагностики, советника и Jev.
Каждая новая функция — за выключателем мода, работает одинаково для Claude, Codex и Grok, кроме явно названных ограничений движка.

## Решения по реализации
- **Где код:** `cloudcli-fork/`, ветка `feat/neo3-workbench-video`; терминальный пакет — `~/.claude/`, `~/.codex/skills/` (вне форка, коммитов там нет; бэкап перед правкой). Прод не трогается до финала.
- **Выключатели:** 7 новых модов в `shared/mods.ts`: `modWorkbench` (стол, инспектор, контекст/лимиты, артефакты), `modSessionHub` (полоса и панель диалогов, мастер-сессия), `modSideChat` (/btw, второй чат, дерево вложенных), `modGroups`, `modThinkingTime`, `modKeepAwake`, `modDiagnostics` (/doctor, /skill-doctor, /advisor, профиль настроек). Ключи не переименовывать после выкатки.
- **Хранение:** артефакты, версии, комментарии — `workspace_records` новыми kind (без миграции); снимки содержимого — `~/.cloudcli/artifacts/<id>/` (текст до 2 МБ, бинарь до 20 МБ, больше — только метаданные); группы и закрепы — своя таблица (кросс-проектные, по пользователю); время размышления — колонка `thinking_ms` в `run_durations`; раскладка рабочего стола — ui-preferences ключ `workbenchLayout` (JSON-строка).
- **Агентные инструменты** — только через существующий neo3-threads MCP (`workspace_action` новые действия): одна точка для трёх движков, токен прогона, без отправки/удаления.
- **Предпросмотр HTML** — существующий file-preview (sandbox, CSP без сети); нового iframe-механизма нет.
- **Модель для «Подготовить ответы» и /advisor** — `runHeadlessPrompt({readOnly:true})` (как у Дуэта), Claude; сбой — понятный текст, без падения.
- **Время размышления** — замер в реестре прогонов (единственная точка всех движков): интервал «предыдущее событие → событие thinking», подряд идущие thinking продлевают интервал, сумма за ход. Привязка к ответу — тем же `attachRunDurations`.
- **Тема** — один блок CSS на токенах + хвосты по образцу тёмной `claude`; шрифт с засечками свободной лицензии (Source Serif 4 или Newsreader) через Google Fonts; не копировать фирменные шрифты/логотипы Anthropic.
- **Слэш-команды** /btw, /doctor, /skill-doctor, /advisor — серверный реестр `builtInCommands` + клиентский `handleBuiltInCommand`.
