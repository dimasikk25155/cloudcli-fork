# Предложение памятки: HTML-превью Neo3 (без записи во внешнюю память)
- Код: `server/modules/file-preview/`, `src/components/code-editor/`; подключение маршрутов — `server/index.js`.
- `POST /api/projects/:projectId/files/preview {path}` требует авторизацию и доступ к проекту, использует существующий resolver; ответ `{url,expiresAt}`. `GET/HEAD /api/file-preview/:token/*` обслуживает документ/ресурсы по отдельному capability-токену, без общего JWT в URL.
- Grant хранится в памяти 30 минут (рестарт обнуляет, лимит 500); доступ к проекту перепроверяется. Корень — проект, для HTML вне проекта только у админа — папка документа; realpath и allowlist расширений ограничивают ресурсы, dotfiles/secrets/credentials запрещены.
- Отдельный край: запрещённые компоненты внешнего корня исчезают из относительного пути; проверять сам корень при issue. Исправление dffd551f подтверждено тремя регрессиями и независимой повторной проверкой: targeted 8/8.
- CSP `sandbox allow-scripts` и iframe без `allow-same-origin`; `connect-src 'none'`, `form-action 'none'`, `nosniff`, `no-store`, `no-referrer`. Это статическое превью сохранённого файла, не dev-server приложения.
- Относительные CSS/JS/media и ссылки на родительские папки работают в пределах корня; корневые `/...` не переписываются, UI предупреждает о возможном отсутствии оформления. Не обещать поддержку backend/API или всех сборщиков.
- `.html/.htm` открываются как превью по умолчанию, diff остаётся кодом; переключение кода/превью, новая вкладка, загрузка/ошибка/повтор. `useHtmlPreview` делает HEAD до iframe; Markdown и media сохраняют прежние ветки.
- Выборочные тесты из `cloudcli-fork/`: `preview_test_dir=$(mktemp -d /tmp/neo3-preview-tests.XXXXXX); env HOME="$preview_test_dir" DATABASE_PATH="$preview_test_dir/auth.db" node_modules/.bin/tsx --tsconfig server/tsconfig.json --test server/modules/file-preview/tests/file-preview.test.ts src/components/code-editor/utils/documentPreview.test.ts`.
- По переданным результатам: typecheck PASS, полный npm test 1598/1598, build в чистом клоне PASS, scoped tests PASS; независимый HTTP POST/HEAD/GET с реальным resolver и пробелами/кириллицей PASS. После исправления внешнего корня: scoped 8/8, независимый HTTP 2/2 и build:server в чистом клоне PASS.
