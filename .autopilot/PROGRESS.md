# Neo3 — возможности Grok Bot, второй чат, рабочий стол — что осталось

Последняя сборка: `.autopilot/2026-11-05-grokbot-powers/` — в Neo3 появились агенты с ролью, самопроверкой и памятью, штаб с помощниками по имени агента, конвейер с вердиктом и браком, рутины от имени агента с итогом Диме, запрос ключа через «Ждут тебя» и разбор `docs/grokbot-in-neo3.md`. Код — в ветке `feat/neo3-grokbot` (worktree `claude agent/neo3-grokbot`, от `feat/neo3-safari-second-chat`). На боевой Neo3 НЕ выкачено, в `cloudcli-fork` не влито.

## Договорились — не пересматривать
- Второй чат справа = тот же `ChatInterface` с `embedded`, а не своя упрощённая лента (Дима 05.11: «второй чат должен выглядеть аналогично первому, иначе смысла нет»).
- Глобальное (звуки, `[Done]`, сторож соединения, быстрые настройки, бар всех проектов, материалы «Отправить агенту», выбор движка) делает только основной чат.
- Рабочий стол переключаемый, обычный чат остаётся; мод выкл — прежний переключатель вкладок.
- Мастер-сессия по всем проектам Димы, отправка после показа адресатов; права тиммейтов не расширять.
- Браузер агентов — только Safari; Chrome/Playwright не использовать.
- Тему `claudeLight` Диме НЕ включать. Облачные проекты на VPS и кнопки ответа у Codex — не делать. Motion — «уже есть».
- Прод и рестарт — только с согласия Димы; строить в отдельном worktree, `cloudcli-fork/` не трогать.
- Менять MCP-серверы и навыки может только админ; тиммейту значения env/headers/args не отдаются.
- Правка артефактов идёт над исходником файла, не над живой страницей (ADR 0024); конфликт с агентом — по содержимому файла (ADR 0026).

- «grok bot» = Grok Bot от xAI, «наш cli» = Neo3 (допущение сборки 05.11 в полном автомате — Дима ещё не подтвердил).
- Роль агента — скрытый блок `<agent_brief>` в первом сообщении, не системный промпт (одинаково на трёх движках) — ADR 0030.
- Из Grok Bot сознательно не переносим: облачную VM, Routines по событию, Skills показом, групповой чат ботов, «бот создаёт ботов», генерацию, плагины Cursor — ADR 0035.

## Известные баги
- Метка агента уходит всем участникам проекта в кадре `session_upserted` (список чатов её тиммейту уже не отдаёт); тиммейт в общем проекте может прочитать роль агента в истории чата.
- Чат с агентом на Claude стартует в обычном режиме разрешений — первое действие может прийти вопросом в «Ждут тебя».
- Прогоны конвейера и рутин без токена тредов: там агент не может `agent.remember` / `secret.request`; помощник-агент в штабе работает в папке штаба.
- Конвейер: выключение мода на последнем пункте может съесть итог; сервер разрешает удалить идущую очередь и «Отметить OK» нетронутый пункт; удаление агента посреди тика пропускает остальные очереди до следующего.
- Списки моделей агентов скопированы из тредов; агента можно сохранить в архивной папке; счётчик «Ждут тебя» не считает запросы ключей.
- Чистый клон: `npm ci` падает на husky при `NODE_ENV=production` (агенты Neo3) — `NODE_ENV=development npm ci`; сервер слушает `SERVER_PORT`, не `PORT`.
- Второй чат: сторож соединения один (левый) — если ход идёт только справа и сокет полуоткрыт, правый может замереть до переподключения.
- Второй чат: очередь справа отправляет общий автоотправщик — уходит один раз, но без мгновенного локального пузыря.
- Второй чат: движок свежего `/btw` хранится в памяти — после перезагрузки, пока чата нет в списке, Grok/Codex-чат справа может показать Claude.
- Автопилот опрашивается 2–3 раза каждые 15 с (шапка, холст, вкладка).
- Терминал переподключается, если холст скрыть целиком (между вкладками холста держится).
- При включённом рабочем столе в теме codex нет кнопки «Изменения» (Git), вкладки Git в холсте нет.
- Ручки размера только справа, снизу и в углу; протяжка цвета при нескольких выделенных — шаг отмены на каждое движение.
- Отложенная просьба агенту ждёт вкладки артефакта в исходном чате и уходит через паузу 800 мс — риск попасть не в тот чат.
- Рейка слайдов после каждой правки заново снимает все кадры — на длинной колоде тормоза.
- Самопроверка `?neo3EditorSelfTest=1` есть в боевой сборке (локальная, без сети).
- Записи `master-send` не удаляются из базы (срок проверяется при чтении); копия SVG в редакторе отдаётся как HTML.
- Тиммейту виден список навыков любой папки (только чтение); запись правки на диск не дописывает остаток при частичной записи.
- Тема аккаунта применяется после перезагрузки; у Codex нет «думал N с», фон подписан «zsh».
- Хвосты вне форка (убирает Дима): `~/.claude/skills/skill-doctor` (+ ссылка в `~/.codex/skills`), `~/.claude/projects/-private-tmp-t04-live-cproject`, `/tmp/t04-live`, логи `claude agent/.playwright-mcp/`.
