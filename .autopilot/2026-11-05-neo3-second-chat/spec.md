# Спецификация: второй чат справа — как основной

## Задача
Дима работает в двух чатах сразу: основной слева, второй — во вкладке «Второй чат» на холсте справа.
Справа сейчас бледная копия: строки «• Write • Bash», голое поле ввода, нет модели, effort, кэша,
индикатора «Думает…», кнопок ответа на вопросы. «Иначе это не имеет смысла — могу рядом вторую
вкладку браузера открыть». Нужно, чтобы справа был тот же чат и работал правильно рядом с первым.

## Решение
Во вкладке «Второй чат» (и «Побочный чат» `/btw`) — тот же чат, что слева, тем же кодом:

- **R01** — лента как слева: карточки и группы инструментов, Markdown, картинки, «думал N с», копирование.
- **R02** — композер как слева: «+», режим, модель, effort, контекст %, кэш, лимиты, микрофон, стоп.
  Модель/effort — этого чата (сессии справа), список моделей — только своего движка.
- **R03** — индикатор хода («Думает… 27с», текущий инструмент) и «Стоп esc» над композером.
- **R04** — что набрано справа, уходит только в чат справа; левый не трогается.
- **R05** — вопросы агента справа (кнопки ответа, план, разрешения) отвечаются прямо справа.
  Очередь сообщений справа — как слева: набранное во время хода встаёт карточкой и уходит после хода, один раз.
- **R06** — оба чата могут отвечать одновременно: тексты не смешиваются, «Стоп» и спиннер не гаснут от
  чужого чата. Это чинит и живой баг: сейчас стрим второго чата подмешивается в пузырь первого.
- **R07** — двойной Esc останавливает только тот чат, в котором стоит курсор (Esc с пустого места —
  основной, как раньше).
- **R08** — у каждого чата свой черновик поля ввода; после перезагрузки страницы черновик справа на месте.
- **R09** — переключение вкладок холста не сбрасывает чат справа: прокрутка, идущий ответ, черновик на месте
  (открытые чат-вкладки остаются смонтированными, скрытыми).
- **R10** — выпадашки композера (модель, effort, `/`-меню, вложения) не выходят за правый край окна —
  у обоих чатов.
- **R11** — два живых чата рядом. Глубже:
  - R11.1 — чат справа открыт и закончил ход → отметка «готово» в сайдбаре гаснет (просмотрено), как у левого.
  - R11.2 — `/btw` и `/advisor`, набранные справа, открывают вкладку на этом же холсте (видимом).
  - R11.3 — переходы внутри правого чата (эстафета «Перенести», треды, «открыть дочерний чат»)
    перенацеливают вкладку справа, а не уводят левый чат.
  - R11.4 — сбой рендера правого чата не роняет страницу: строка «Чат не открылся» + «Открыть чат целиком».
  - R11.5 — нет связи / переподключение — справа как слева (тот же баннер), без второго сторожа соединения.
- **R12i** — «Побочный чат» (`/btw`) — тот же вид. Свежий побочный чат, которого ещё нет в списке проекта,
  открывается сразу (сессия собирается из id, движка и проекта), первая отправка не создаёт новый чат.
- **R13i** — левый чат без изменений: навигация, «Новый чат», звуки и «(N)/[Done]» во вкладке браузера
  срабатывают по одному разу (их делает только левый), глобальный выбор движка не переписывается правым.
- **R14** — выкатка на боевой Neo3 из worktree `claude agent/neo3-second-chat` (ветка `feat/neo3-second-chat` от 5ba10b83): только клиент (`dist/`), без рестарта; копия прежнего `dist` и
  ROLLBACK.txt в `~/.cloudcli/maintenance/second-chat-release-<время>/`; коммит в `feat/neo3-second-chat`.

Над чатом справа остаётся узкая строка вкладки: название, статус («Работает/Ждёт ответа/Готово/Ошибка»),
«Открыть чат целиком». Выбор чата для пустой вкладки «Второй чат» и выключатель мода — как сейчас.

## Решения по реализации
- Справа рендерится тот же `ChatInterface` с пропом `embedded` — единственный способ получить «аналогично»,
  не держа вторую копию UI (ChatMessagesPane/ChatComposer — ~115 пропов из четырёх хуков).
- Живые баги B1/B2 чинятся для всех экземпляров (буфер стрима по sessionId; `chat_subscribed` — только свои).
- Всё глобальное (звуки, заголовок, сторож соединения, ручка быстрых настроек, бар всех проектов,
  запись `selected-provider`, window-события композера) делает только неembedded-экземпляр.
- Рабочие данные чата (processing-набор и колбэки, `onFileOpen`, настройки UI) приходят на холст через
  `WorkbenchRenderContext` из MainContent.
- Старый упрощённый код ленты (`feedRows`, `chatSendFrame`, черновики/скролл `sideChatStore`) удаляется
  вместе с тестами; `chatPickerChoices`, `sideChatTabFor`, движок в `sideChatStore` остаются.
- Сервер не меняется.
