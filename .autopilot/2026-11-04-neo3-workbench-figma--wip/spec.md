# Спецификация: доделки рабочего стола Neo3 и правка артефактов «как в Figma»

## Задача
Дима работает в Neo3 с рабочим столом (чат + холст). Шапка забита вкладками, которые дублируют холст; на телефоне она ломается. Длинные списки шагов помощника забивают чат. Несколько мелких багов прошлой сборки мешают каждый день. А главное — артефакт (HTML-макет, инфографику, слайды) нельзя поправить руками: даже чтобы сдвинуть заголовок или поменять цвет, приходится писать агенту и ждать.

## Решение
- Шапка: только чат как основной вид и индикаторы (колокольчик, боты, «Несохранённые правки», кнопка холста). Терминал, Файлы, Статистика, Автопилот и вкладки плагинов открываются вкладками холста из одного меню «+» вместе с Инспектором, Контекстом и лимитами, Результатами. Мод рабочего стола выключен — всё как раньше.
- В панели диалогов — «Прочитать всё»; серии шагов помощника свёрнуты в одну строку.
- Исправлены баги прошлой сборки (см. истории R03–R10).
- Артефакт открывается в холсте в режиме «Правка»: выделяешь элементы мышкой, двигаешь, меняешь размер, текст, цвет, шрифт, отступы, слои; отмена/повтор, привязка к сетке и соседям; «Сохранить» пишет файл новой версией и не затирает параллельную правку агента. Сложное — «Попросить агента» по выделению: сообщение в исходный чат с путём, селектором, снимком участка и просьбой; новая версия от агента ловится сама и показывается разницей. Слайды — кадрами с миниатюрами и перетаскиванием, масштаб 25–400 %. Работает на Claude, Codex и Grok, за модом «Правка артефактов».

## Решения по реализации
- **`data-neo3-id` живёт одну сессию правки.** Id ставятся заново при каждом открытии (порядок обхода исходника). Чтобы переиграть правки на изменённом агентом файле (R22.1), каждая операция при записи в стек запоминает «отпечаток» элемента — CSS-путь по тегам и индексам + начало текста; при переигрывании элемент ищется по отпечатку, не нашёлся — операция пропускается и учитывается.
- **Правка = операции над исходным текстом, не над живым DOM.** Клиент разбирает исходник `DOMParser` (скрипты не выполняются), проставляет каждому элементу `data-neo3-id` по порядку обхода, добавляет инлайн-мост в начало `<head>` и отдаёт эту копию в превью. Операции применяются и в iframe (мостом, для вида), и в разобранной копии исходника (для сохранения). Сохранение = сериализация копии без `data-neo3-id`. Так в файл не попадает ни мост, ни то, что нарисовали скрипты страницы. Цена: сериализация `DOMParser` нормализует разметку (кавычки, пустые теги) — первая правка может показать в разнице больше строк, чем менялось. ASSUMPTION.
- **Отдача копии с мостом — через file-preview:** новый вид гранта «копия документа» — сервер хранит присланный клиентом HTML (≤2 МБ) в памяти гранта и отдаёт его по адресу исходного файла внутри токена, остальные ресурсы — с диска как раньше, CSP тот же. Почему: относительные пути картинок и CSS работают, `srcdoc` их ломает (`base-uri 'none'`).
- **Сохранение:** `artifactsService.saveEdit(userId, projectId, id, {content, baseVersionN})` — guard + мод `modArtifactEditor` + размер ≤ текстового лимита + sha файла на диске = sha версии `baseVersionN` (иначе 409 `ARTIFACT_EDIT_CONFLICT` с текущей последней версией) + запись по проверенному realpath + версия `source:'edit'`. Почему: ревизия записи не ловит прямую правку файла агентом, хэш — ловит.
- **Снимок участка без новых пакетов:** мост клонирует выделенный элемент с вычисленными стилями в SVG `foreignObject` → canvas → PNG; внешние картинки могут не попасть (CSP) — тогда снимок без них; ошибка → без снимка. Растровый артефакт — обрезка картинки в canvas родителя. Отправка картинки — расширение `sendToComposer(text, {autoSend, images?: File[]})`. ASSUMPTION.
- **Новая версия от агента:** опрос `refresh` (без нового WS-кадра) — 5 с в течение 10 мин после «Попросить агента», иначе 30 с пока вкладка видна.
- **Вкладки в холсте:** новые виды регистрируются как остальные; `WorkbenchRenderContext` получает `onFileOpen` и `isActive`; определение вида получает флаг `keepMounted` (холст держит такие вкладки смонтированными скрытыми). Автопилот — `useAutopilotDashboard(projectId)` внутри вида.
- **Мастер-сессия:** без новой таблицы — `workspace_records` kind `master-send`.
- **MCP:** для не-админа значения env/headers убираются (форма ответа сохраняется) — UI настроек не ломается.
