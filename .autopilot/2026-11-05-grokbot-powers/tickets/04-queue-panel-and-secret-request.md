## Что должно заработать

В меню у админа есть «Конвейер» (`?panel=queue`). Там создаётся очередь: агент, название, пункты по строке, шаблон с `{{item}}`, параллельность и попытки. Видны счётчики и каждый пункт с попытками, вердиктом, причиной и выдержкой. Работают «Ещё проход по браку», «Отметить OK», пауза, продолжение и стоп. Пуш «Конвейер готов» открывает эту панель. Агент может попросить ключ: `workspace_action secret.request{name, why}`. В «Ждут тебя» появляется карточка со скрытым полем, Дима вводит значение или отказывает. Значение уходит только в файл секретов через `secrets-stash`, агент получает лишь «NAME сохранён» или «Дима отказал».

## Критерии приёмки

- [ ] Пункт «Конвейер» виден только админу при `modAgentQueue`; `?panel=queue` и переход из пуша `queue.done` открывают панель
- [ ] Панель создаёт очередь и показывает прогресс (опрос 5 с, пока открыта), пункты с попытками/вердиктом/причиной/выдержкой; кнопки пауза/продолжить/стоп/«Ещё проход по браку»/«Отметить OK»; пустая очередь и ошибки — понятным текстом; модель `agentQueueModel.ts` покрыта тестом
- [ ] `secret.request` проверяет имя `^[A-Z][A-Z0-9_]{2,63}$`, ждёт ответа до 600 с, по таймауту — «Дима пока не ответил — спроси позже» (запрос остаётся) — тесты
- [ ] `GET /api/secret-requests` без значений; `POST /:id {value, replace?}` пишет через `secrets-stash`, существующее имя без `replace` — отказ «такой ключ уже есть»; `POST /:id/decline`; admin + `MOD_OFF` — тесты
- [ ] Значение не попадает в ответ агенту, лог, WS-кадр (`secret_requests_changed` без содержимого), уведомление, БД — тест проверяет, что значение не встречается в ответе инструмента и в кадрах
- [ ] Карточка в хабе «Ждут тебя»: поле `type=password`, `autocomplete=off`, значение очищается из состояния после отправки; пуш «Агент просит ключ NAME» без значения
- [ ] Тиммейт не может вызвать `secret.request` (отказ); мод выкл → `modOffMessage`
- [ ] Описание `secret.request` в `threads-mcp.ts`; `npm run typecheck` и `npm test` зелёные
- [ ] Боевое не тронуто: ни `npm run build`, ни рестарта, ни правок `~/.claude*`, `~/.codex`, LaunchAgents; тесты второго чата, Safari вживую, новой вкладки и рабочего стола зелёные
