## Что должно заработать

В меню слева у админа есть пункт «Агенты» (`?panel=agents`): список агентов, создание и правка (имя, роль, «Проверка результата», движок/модель/effort из разрешённых, папка проекта, файлы-знания), память правил с версиями (добавить, удалить, история V1…Vn) и кнопка «Новый чат» с полем задачи. Кнопка открывает созданный чат. Чаты агента в сайдбаре помечены его именем. Штаб-чат открывает помощника по имени: `spawn_thread{agent:"Критик"}` — у треда роль, память, движок и модель агента. `workspace_action agent.list` показывает команду, а `agent.remember` дописывает правило в память агента своего чата.

## Критерии приёмки

- [ ] Пункт меню «Агенты» виден только админу при включённом `modAgents`; `?panel=agents` открывает панель
- [ ] В панели можно создать, изменить и удалить агента; ошибки валидации сервера показываются по-русски рядом с полем; движки и модели берутся из `providerSelectionPolicy`
- [ ] Память: список текущих правил с версией, добавить/удалить, история версий; правило, добавленное агентом, помечено «добавил агент»
- [ ] «Новый чат» с задачей открывает созданный чат; в пузыре видна только задача, без блока роли
- [ ] Чаты агента в сайдбаре несут метку с именем агента
- [ ] `spawn_thread` с `agent` открывает тред с ролью/памятью/движком/моделью агента, явные provider/model приоритетнее; неизвестное имя → `AGENT_NOT_FOUND` со списком имён; мод выкл → `MOD_OFF`; лимит 3 и запрет вложенности прежние — тесты
- [ ] `workspace_action agent.list` и `agent.remember` работают; чат без агента → «этот чат не привязан к агенту»; не-админ → пусто/отказ — тесты
- [ ] Описания инструментов в `threads-mcp.ts` обновлены (агент знает про `agent`, `agent.list`, `agent.remember`)
- [ ] Чистая модель панели `agentsModel.ts` покрыта тестом; `npm run typecheck` и `npm test` зелёные
- [ ] Боевое не тронуто: ни `npm run build`, ни рестарта, ни правок `~/.claude*`, `~/.codex`, LaunchAgents; тесты второго чата, Safari вживую, новой вкладки и рабочего стола зелёные
