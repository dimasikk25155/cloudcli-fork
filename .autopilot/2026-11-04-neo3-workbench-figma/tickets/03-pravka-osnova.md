## Что должно заработать

Есть всё, на чём стоит редактор: сервер сохраняет правку файла новой версией и не затирает параллельную правку агента; отдаёт копию документа с мостом в той же песочнице; мод «Правка артефактов»; модель операций (применение, отмена, сериализация обратно в исходник без следов редактора), протокол моста с проверкой сообщений, привязка к сетке и соседям, поиск кадров-слайдов. Интерфейса ещё нет.

## Из брифа, дословно

> «изменения сохраняются в файл новой версией»
> «Сохранение в исходник: операции хранятся как патч к DOM; при «Сохранить» мост сериализует документ, сервер пишет файл через `artifacts.service` (новая версия `source:'edit'`, проверка `revision` — не затирать параллельную правку агента; путь строго внутри проекта, приватные — отказ). Внешние CSS: правки как inline-style или в `<style data-neo3-edits>` блоке; не ломать скрипты страницы.»
> «мост принимает сообщения только от своего iframe; никакого доступа к cookies/API из макета (sandbox без same-origin, CSP `connect-src 'none'`); тиммейты — только в своих проектах (`projectAccessFor`); мод `modArtifactEditor`, карточка с поддержкой движков.»
> «юнит-тесты модели операций и сериализации; сервис сохранения (revision-конфликт, приватные пути, версии)»

## Критерии приёмки

- [ ] `modArtifactEditor` в `MOD_KEYS`/`MODS` (requires `modWorkbench`, engines «Claude ✓ · Codex ✓ · Grok ✓»), тесты модов зелёные
- [ ] `PUT /api/projects/:projectId/artifacts/:id/edit` пишет файл и создаёт версию `source:'edit'`; файл изменён на диске после `baseVersionN` → 409 `ARTIFACT_EDIT_CONFLICT` с последней версией, файл не тронут
- [ ] Отказы правки: мод выкл (409 MOD_OFF), чужой проект (403), приватный путь/симлинк наружу/подмена ссылки перед записью (400), не html/htm/svg (400), больше текстового лимита (413) — тесты
- [ ] `POST …/:id/editor-preview {html}` → url file-preview, по которому отдаётся присланный HTML с тем же CSP (`connect-src 'none'`, sandbox allow-scripts), а остальные файлы гранта — с диска; тот же набор отказов (тесты роутов)
- [ ] Модель: стек операций (отмена/повтор, лимит 200), `snapRect`, `validateBridgeMessage` (чужой nonce, лишние поля, неверные типы → null), построение порядка кадров — тесты в `npm test`
- [ ] DOM-функции Б1 реализованы; `applyOpToDocument` самодостаточна (тест: `new Function` из её `toString()` создаётся); `buildBridgeScript(nonce)` содержит её и проверяет `event.source === window.parent` и nonce
- [ ] `selftest.ts` `runEditorSelfTest()` проверяет в браузере: instrument → операции каждого типа → serialize даёт ожидаемый HTML; `<script>`/`<style>` исходника байт в байт; нет `data-neo3-id` и моста в результате; SVG; replay по отпечаткам; открывается по `?neo3EditorSelfTest=1` и показывает PASS/FAIL
