## Что должно заработать

Правка артефактов безопасна и надёжна: запись не уходит за пределы проекта даже при подмене ссылок, одновременные сохранения не портят историю, понятный отказ для папок с точкой; тиммейт не видит токенов в MCP и не трогает чужие проекты и навыки Димы; снимки целые; размер не «прыгает»; несохранённые правки не теряются молча; страница не может подсунуть правку текста; редактор помещается на телефоне.

## Из брифа, дословно

> «изменения сохраняются в файл новой версией … проверка `revision` — не затирать параллельную правку агента; путь строго внутри проекта, приватные — отказ»
> «мост принимает сообщения только от своего iframe; никакого доступа к cookies/API из макета … тиммейты — только в своих проектах»
> «`GET /api/providers/:provider/mcp/servers` без `?fields=names` отдаёт тиммейтам значения env — закрыть для не-админа»
> «скриншотом участка»; «миниатюры слева»; «На телефоне — то же меню из кнопки «Холст».»
