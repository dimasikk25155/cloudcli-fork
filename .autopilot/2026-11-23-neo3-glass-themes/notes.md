### Где и чем применяется тема
- Начальное состояние (L271): `localStorage.appTheme || localStorage.shaderVariant`, затем `THEMES.includes(saved) ? saved : DEFAULT_THEME` — неизвестный (удалённый) id молча превращается в `ember`. Миграции id нет.
- Эффект применения (L383–420, зависимости `[theme, themeTweaks]`): `root.setAttribute('data-theme', theme)` (L385) → `localStorage.appTheme` → `applyTweaks(theme, themeTweaks)` → `root.classList.toggle('dark', !LIGHT_THEMES.includes(theme))` → `localStorage.theme = 'dark'|'light'` → `meta[name="apple-mobile-web-app-status-bar-style"]` = `black-translucent` (тёмная) / `default` (светлая) → `readThemeChromeColor` → `localStorage.appThemeColor` (hex), `root.style.backgroundColor`, `meta[name="theme-color"]` → `window.neo3Desktop?.notifyThemeChanged?.({isDark, background})`.
- Предварительная покраска — inline-скрипт `index.html` L56–78: СВОЯ копия `var LIGHT_THEMES = ['editorial','glass','claudeLight']` (L59), читает `appTheme`/`shaderVariant` (дефолт `'ember'`), `appThemeColor` (если не `#rrggbb` → `#141414` тёмная / `#faf9f5` светлая), ставит `data-theme`, `.dark`, `backgroundColor`, `theme-color`, status-bar. НЕ проверяет, что id существует → удалённый id даст `data-theme` без CSS-блока до монтирования React.
- В `index.html` же `<meta name="theme-color" content="#ffffff">`, `apple-mobile-web-app-status-bar-style=black-translucent`, viewport с `viewport-fit=cover, interactive-widget=resizes-content`, шрифты Google (Encode Sans, Merriweather, Geologica, Barlow, Work Sans, Outfit, JetBrains Mono, Source Serif 4).

`appTheme` (id темы; читается и legacy `shaderVariant`), `theme` (`dark|light`), `appThemeColor` (hex), `shaderBg` (`on|off`, показывать ли фон), `themeBackgrounds` (JSON `{тема: id варианта|'auto'}`), `themeTweaks` (JSON `{тема: {radius,…}}`), `uiScale`, `customBackground` (`on|off`). ## 10. Как посмотреть глазами без айфона

### (a) Изолированный сервер из ЭТОЙ копии
- Статика клиента берётся из `<APP_ROOT>/dist` (`server/index.js` L458, L1407; `APP_ROOT = findAppRoot(__dirname)` = корень копии: каталог над `server/`, либо над `dist-server/`), отдельной env-переменной «каталог клиента» НЕТ. `dist/` в `.gitignore` (L10); в этой копии `dist/` свой (живое приложение лежит в `cloudcli-fork`) → `vite build` (без `--outDir`, т.е. в `neo3-glass/dist`) живое не трогает, но это решение за оркестратором: правило из `../CLAUDE.md` — «до финального применения только изолированные сборки». Если `dist/index.html` нет, `GET *` отдаёт заглушку — для UI он обязателен.
- `dist-server` собирать НЕ нужно: `package.json` `server:dev` = `tsx --tsconfig server/tsconfig.json server/index.js` запускает сервер из исходников (`@/`-алиасы разрешает tsx по `server/tsconfig.json`; для `tsc` out-of-tree потребовался бы ещё `tsc-alias`, не нужно).
- Команда (порт 3917 как пример; проверить `lsof -nP -iTCP:3917`; `HOME` обязателен — иначе сервер пишет в боевое `~/.cloudcli`, в т.ч. перезаписывает маркер `~/.cloudcli/local-server.json` (`writeLocalServerMarker`, L1575, `os.homedir()`), а `os.homedir()` на macOS берётся из `HOME`):
```sh
S=$(mktemp -d /tmp/neo3-glass-home.XXXXXX); mkdir -p "$S/.cloudcli"
```
